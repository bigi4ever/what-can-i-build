# What Can I Build? / מה אפשר לבנות?

מצלמים את חלקי הבנייה שמפוזרים על הרצפה, כמו מגנטים, לגו או קוביות, ומקבלים מודל שאפשר
לבנות **בדיוק מהחלקים שיש**, עם הוראות בנייה שלב אחר שלב בתלת-ממד.

## הרצה

דרוש Node 20 ומעלה. אין תלויות להתקנה.

```bash
npm run serve        # http://localhost:8080/web/
npm test             # בדיקות
npm run check -- models/magnetic-frames/castle.json inventories/magnets-photo-1.json
```

התצוגה טוענת את three.js מ-cdn.jsdelivr.net, ולכן צריך חיבור לאינטרנט.

## מבנה

```
src/core/        גיאומטריה, בודק תקינות והתאמת מודלים למלאי (בלי תלויות, רץ ב-Node ובדפדפן)
src/systems/     מודולי חוקים לכל סוג חלקים (כרגע: magnetic-frames)
models/          מודלים לדוגמה
inventories/     רשימות מלאי
web/             תצוגת התלת-ממד
docs/            פורמט המודל (docs/model-format.md)
```
